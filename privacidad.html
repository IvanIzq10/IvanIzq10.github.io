Política de privacidad

Información general sobre el uso de esta web y sus herramientas.

Nota importante: esta es una plantilla informativa básica. Antes de añadir analítica, publicidad, formularios o servicios externos, revisa y adapta esta política a las prácticas reales del sitio y a la normativa aplicable.

1. Herramientas y datos introducidos

Las calculadoras y el contador de palabras procesan los valores y textos introducidos en el navegador del usuario. El organizador de tareas utiliza almacenamiento local del navegador para conservar la lista en ese dispositivo. No introduzcas contraseñas, datos sensibles ni información confidencial en estas herramientas.

2. Alojamiento y registros técnicos

Este sitio se publica mediante GitHub Pages. El proveedor de alojamiento puede procesar datos técnicos de conexión conforme a sus propias condiciones y políticas. Consulta la documentación y la política de privacidad del proveedor para obtener información actualizada.

3. Cookies y servicios de terceros

Esta versión del sitio no incorpora deliberadamente herramientas propias de analítica ni publicidad. Si se añaden servicios de terceros en el futuro, esta página debe actualizarse para describirlos con precisión y explicar las opciones disponibles al visitante.

4. Conservación y control

La lista de tareas se guarda localmente en el navegador utilizado. Puede eliminarse desde la propia herramienta o mediante la limpieza de datos del navegador. La disponibilidad de los datos depende del dispositivo y del navegador.

5. Enlaces externos

La web puede enlazar a servicios externos. UtiliLab no controla las políticas ni el contenido de esas páginas; revisa sus condiciones antes de compartir información.

6. Contacto y actualizaciones

Para sugerir una corrección puedes consultar el repositorio de UtiliLab en GitHub. Esta política debe revisarse si cambian las funciones, el alojamiento o los servicios usados.
