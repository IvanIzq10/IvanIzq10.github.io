UTILILAB — VERSIÓN MEJORADA
================================

Contenido:
- index.html: portada
- herramientas/: calculadora de porcentajes, contador de palabras, conversor y organizador de tareas
- guias/: índice y tres guías
- sobre.html, privacidad.html, aviso-legal.html
- assets/: CSS, JavaScript común e icono
- robots.txt y sitemap.xml

CÓMO PUBLICAR EN GITHUB PAGES
1. Descarga y descomprime este ZIP.
2. Entra en el repositorio https://github.com/ivanizq10/ivanizq10.github.io
3. Sube los archivos y carpetas que están DENTRO de la carpeta utililab_mejorada, no la carpeta contenedora.
4. Si GitHub pregunta, confirma los cambios (Commit changes).
5. Espera unos minutos y abre https://ivanizq10.github.io/

IMPORTANTE
- Haz una copia del repositorio actual antes de sustituir archivos.
- Esta versión está preparada para GitHub Pages y usa rutas absolutas desde la raíz del dominio.
- sitemap.xml enumera las páginas principales y robots.txt apunta a él. Search Console puede tardar en actualizar su estado.
- La política de privacidad y el aviso legal son plantillas generales. Adáptalos a las prácticas reales y requisitos aplicables antes de monetizar.
- Si añades publicidad, analítica, formularios o servicios externos, actualiza la política de privacidad y las opciones de consentimiento que correspondan.
- No se garantizan indexación, visitas ni ingresos.
